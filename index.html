여행 계획과 기록은 오프라인에서도 이어집니다

여행 계획과 기록은 이 브라우저에 저장되어 오프라인에서도 확인하고 기록할 수 있습니다. AI 생성, 새 지도 타일, 환율 갱신과 외부 백업에는 인터넷 연결이 필요합니다.

1 여정 등록 및 4대 상태 관리

메인 허브에서 [+ 새 여행 만들기]를 눌러 여행명, 기간, 방문 국가 및 통화를 설정합니다. 날짜가 정해지지 않은 꿈의 여행지는 [버킷리스트]로 등록하고, 출발일이 다가오면 자동으로 [예정(D-Day)] → [진행 중] → [완료]로 전환됩니다. 카드 좌측의 컬러 그라데이션과 하단 진행률 바로 현재 여행의 진척도를 한눈에 체감할 수 있습니다.

2 30분 스마트 타임라인 & 유연한 일정 재배치

여행 워크스페이스의 [오늘 동선] 탭에서 30분 단위로 세밀한 스팟 일정을 관리하세요. 일정 순서 조정, 완료 체크, 고정 핀(Pin) 설정이 가능합니다. 현지에서 예기치 않게 일정이 밀렸을 때 [일정 재배치]를 누르면 고정된 스팟을 보존하면서 나머지 일정을 현실적으로 자동 재배분해 줍니다.

3 다통화 스마트 가계부 & MEP 현지 환율

달러(USD), 유로(EUR), 엔화(JPY)뿐 아니라 아르헨티나 페소(ARS, MEP 블루 환율), 페루 솔(PEN), 볼리비아노(BOB) 등 다중 통화를 지원합니다. 지출 시 현지 통화로 입력하면 원화(KRW)로 자동 환산되어 목표 예산 대비 지출율(%)을 실시간 추적할 수 있습니다.

4 Gemini AI 대화형 여행 비서

설정(⚙)에서 본인의 Google AI Studio API 키를 등록하면, 여행 생성 시 [AI 맞춤 일정 생성]을 통해 현지 최적화된 8~12개 추천 스팟을 자동으로 설계받을 수 있습니다.

여행 사본을 내보내 다른 기기에 수동으로 복원합니다

먼저 — 술술트래블의 데이터 주권 철학

여행 데이터는 기본적으로 이 브라우저에 저장됩니다. 백업 파일이나 GitHub Gist를 사용하면 선택한 여행 데이터가 해당 파일 또는 서비스로 복사됩니다. 이 과정은 기기 간 실시간 동기화가 아닙니다.

방법 1. JSON 파일 백업 & 복원 (가장 간편하고 안전) 추천
  1. 상단 설정(⚙) 아이콘을 클릭합니다.
  2. [전체 백업 (JSON)] 버튼을 눌러 여행 데이터 백업 파일을 다운로드합니다.
  3. 다운로드된 sulsul_travel_backup_....json 파일을 카카오톡(나에게 보내기), 메일, 에어드롭 또는 클라우드로 다른 기기로 전달합니다.
  4. 다른 기기에서 설정(⚙) → [백업 파일 복원]을 선택합니다. 복원하면 그 기기에 있던 여행 목록 전체가 백업 파일의 목록으로 교체되므로, 먼저 대상 기기도 백업하세요.
방법 2. GitHub Gist 개인 백업

GitHub 토큰(PAT)을 연결하면 Gist로 직접 백업·복원할 수 있습니다. Secret Gist는 검색에 나타나지 않지만 링크를 아는 사람이 볼 수 있습니다. 일기·사진의 포함 내용을 확인하고 토큰을 동행자에게 전달하지 마세요. 공동편집 기능은 아닙니다.

⚠️ 스마트폰 변경 또는 브라우저 캐시 삭제 전 주의사항:

기기를 변경하거나 브라우저 쿠키/데이터를 초기화하면 기기 내 데이터가 지워질 수 있습니다. 중요한 여행 전후에는 반드시 설정(⚙)에서 JSON 백업 파일을 안전하게 저장해 두세요.

3. 외부로 나가는 통신 (투명한 전부 고지)

  • 화면 글꼴: Google Fonts 및 jsDelivr에서 글꼴 스타일을 불러옵니다.
  • 지도·환율: 지도를 열면 OpenStreetMap 타일을, 환율 갱신을 누르면 open.er-api.com을 요청합니다. 지도 링크를 누르면 검색어 또는 좌표가 Google Maps로 전달됩니다.
  • Gemini AI: 사용자가 AI 기능을 실행할 때 해당 요청에 필요한 여행 설명·일정·일기 문장 또는 영수증 사진이 브라우저에서 Google API로 전송됩니다. API 키도 요청 인증에 사용됩니다.
  • GitHub Gist: 사용자가 백업/복원을 실행할 때 여행 전체와 입력한 PAT가 GitHub API로 전송됩니다. Secret Gist는 링크를 아는 사람에게 공개될 수 있습니다.
  • 여행 공유: 링크·파일에는 선택한 일정, 기록, 금융 정보가 포함될 수 있습니다. 링크를 받은 사람은 링크에 들어 있는 내용을 볼 수 있으며 실시간 공동편집은 아닙니다.
  • 선택형 공동 계획: 사용자가 연결·게시·참가·확인·전송을 누르면 설정한 Supabase 서버로 로그인 정보·초대 토큰·공동 계획을 요청/전송합니다. 개인 글·사진·지출은 보내지 않으며 여행 목표 예산·일정 메모는 계획에 포함됩니다. 설정 저장만으로 여행을 전송하지 않습니다.

4. 데이터의 파기 및 주권

여행 카드의 삭제 기능으로 해당 여행을 이 브라우저에서 삭제할 수 있습니다. 중요한 데이터를 지우기 전 JSON 백업을 권장하며, 브라우저 저장소를 비우면 남은 로컬 데이터도 삭제됩니다. GitHub Gist와 공동 서버에 게시한 계획은 별도로 관리·삭제해야 합니다. API 키·GitHub PAT·공동 서버 임시 로그인은 브라우저 저장소에 암호화되지 않은 상태로 보관되므로 공유 기기에서 사용하지 마세요.
