📢 앱 실행 / 설치 시 비행기 아이콘이 뜨는 이유 & 10초 해결법

스마트폰에 이미 설치된 술술트래블 앱(WebAPK)은 OS 내부 패키지에 이전 비행기 아이콘이 영구 고정되어 있어, 웹사이트가 업데이트되어도 실행 화면(스플래시)과 홈 아이콘이 자동으로 바뀌지 않습니다.

👉 새 황금 날개 곰돌이 아이콘 적용 방법 (10초):
  1. 스마트폰 홈 화면에서 기존 '술술트래블' 앱을 길게 눌러 [설치 삭제(삭제)]합니다.
  2. 브라우저(Chrome / 삼성 인터넷)로 술술트래블에 다시 접속합니다.
  3. 브라우저 메뉴(⋮)에서 [앱 설치] 또는 [홈 화면에 추가]를 진행하면 새 공식 곰돌이 아이콘으로 즉시 설치됩니다!

최신 버전

사용자 제안에 따라 메인 허브 화면의 모바일 사용성을 극대화하는 4대 혁신을 완수했습니다. 1) 시작 가이드(PWA 설치 배너) 닫기 시 로컬 스토리지에 영구 기억하여 새 탭마다 화면을 가리지 않도록 최적화하고, 설정 모달에서 언제든 1-클릭으로 복원할 수 있도록 연결했습니다. 2) 컴팩트 리스트 뷰 모드를 전면 개편하여 투톤 다크모드를 완벽 지원하고, 모바일에서 한 화면에 4~5개 여정을 일목요연하게 조망할 수 있는 고밀도 레이아웃을 제공합니다. 3) 모바일 터치 스와이프(좌측 밀기) 제스처를 도입하여 네이티브 앱처럼 부드럽게 [📋 복제] [📄 PDF] [🗑️ 삭제] 퀵 서랍이 열리도록 구현했으며, 원클릭 여정 복제(사본 생성) 기능을 신설했습니다. 4) 통계 모달의 방문 국가 칩을 누르면 전 세계 비행 궤적 노선도에서 해당 국가의 여정과 거점이 즉시 하이라이트되며, 요약표 행 터치 시 해당 여정으로 즉시 진입하도록 유기적으로 연동했습니다.
