# 술술트래블 (Sulsul Travel)

> 현재 작업 버전: **v1.8.6** · 여행 계획, 현장 기록, 가계부와 여행 회고를 한곳에 모으는 오프라인 우선 PWA.

술술트래블은 개인 브라우저에 여행 데이터를 저장하는 정적 웹 앱입니다. Gemini AI는 사용자가 요청할 때 계획·기록 초안을 돕고, 최종 일정과 기록은 사용자가 검토하고 저장합니다.

## 지금 할 수 있는 일

- **큰 계획과 상세 일정**: 여행지를 거점으로 묶고 날짜·숙소·우선순위를 편집합니다. 거점이나 선택한 날짜 범위만 AI로 다시 제안받을 수 있습니다.
- **여행 중 일정 조정**: 오늘 화면에서 다음 일정, 완료 상태, 이동 정보와 RePlan 제안을 확인합니다. 완료·고정 일정은 재생성 보호 대상으로 취급합니다.
- **여행 기록**: 하루 기록은 날짜별 한 편, 일정 기록은 각 일정별 한 편을 저장합니다. 일정 기록에는 사진과 글을 남기고 AI 윤문 제안을 비교·승인할 수 있습니다.
- **가계부**: 여러 통화의 지출·환전·예산을 관리하고 지출 거래와 사진을 편집합니다. 영수증 OCR은 사용자가 요청할 때 실행됩니다.
- **여행 공유와 백업**: 작은 일정 사본은 길이 제한 안에서 링크로 복사하고, 큰 데이터는 JSON 파일로 전달할 수 있습니다. GitHub Gist는 개인 백업이며 실시간 공동편집은 아닙니다.
- **여행 보고서**: 저장된 일정·기록·사진·지출을 바탕으로 보고서를 확인하고 출력합니다. 입력하지 않은 날씨·감정·방문 사실을 실제 기록처럼 채우지 않는 것이 원칙입니다.
- **오프라인 사용**: 캐시된 앱과 기기 저장 데이터는 네트워크 없이 볼 수 있습니다. AI, 새 지도 타일, 환율 갱신, Gist 백업에는 네트워크가 필요합니다.

## 데이터와 개인정보

- 전체 여행 데이터는 `localStorage`의 `st_trips_v2` 한 문서에 저장됩니다. 여행 사진도 현재는 이 문서에 압축된 이미지 데이터로 포함되므로 브라우저 저장 용량이 찰 수 있습니다.
- 저장 공간 초과 때 하루 일기 텍스트를 임시 보관하는 IndexedDB 경로가 있습니다. 사진을 포함한 모든 데이터를 IndexedDB로 이전한 상태는 아닙니다.
- `st_gemini_key`와 `st_github_pat`은 브라우저 저장소에 암호화되지 않은 상태로 보관됩니다. 공유 기기에서는 사용하지 마세요.
- AI 실행 시 요청에 필요한 여행 설명, 일정·일기 텍스트 또는 사용자가 선택한 영수증 이미지가 Google Gemini API로 전송됩니다. Gist 백업은 전체 여행 데이터를 GitHub로 보냅니다. 공유 파일과 링크에는 선택한 기록·금융 정보를 넣을 수 있습니다.
- Gist 복원은 현재 기기의 여행 목록 전체를 백업 내용으로 교체합니다. 복원 전에 현재 데이터를 별도 백업하세요.

## 아직 지원하지 않는 동작

- 같은 날 일정과 연결되지 않은 순간 기록을 원하는 만큼 추가하는 기능은 아직 없습니다. 하루 기록 한 편과 일정별 기록으로 운영합니다.
- 동행자 초대 후 여러 사람이 같은 여행을 실시간 편집하는 기능은 아직 없습니다. 링크·파일은 시점이 고정된 사본입니다.
- 사진 보존 용량 확대를 위한 완전한 IndexedDB 미디어 저장소와 자동 이전은 후속 과제입니다. 기기 변경·브라우저 데이터 삭제 전에 JSON 백업을 만드세요.

## 구조

```text
index.html                         앱 셸, 화면, 기존 화면 로직
js/domain/                         여행 사본 계약, RePlan 도메인
js/application/                    AI 작업 오케스트레이션
js/infrastructure/storage/         여행 저장소, 일기 초과 저장소
js/presentation/                    동행 화면, 기록 편집, 지출 편집, 공유 UI
js/destinations/                    기본·남미·원난 목적지 지식 팩
kb-travel.js                       예시 여행·초기 여행 템플릿
sw.js                              앱 셸 오프라인 캐시
css/                               앱 스타일 및 로컬 유틸리티 CSS
tests/                             계약·브라우저 통합 검사
```

앱은 Vanilla JavaScript 기반의 정적 PWA이며 온라인 계정 서버는 없습니다. AI 작업은 초안으로 보관한 뒤 사용자가 승인해야 원본 일정이나 기록에 적용됩니다. 세부 목표 아키텍처와 단계는 [확장 아키텍처](docs/architecture-vnext.md), [개발 모델](docs/development-model.md), [제품 검토 기록](docs/review-v1.7.8-2026-09-13.md)을 참고하세요.

## 로컬 실행과 검증

PowerShell에서 저장소 루트의 `.\tools-serve.ps1`을 실행하고 `http://localhost:8080/`을 엽니다. PWA와 서비스워커 검증에는 `file://` 대신 localhost를 사용합니다.

Node.js 18 이상이 있는 환경에서는 다음을 실행합니다.

```powershell
node --test tests/*.test.mjs
node tests/activity-journal.browser.cjs
node tests/expense-editor.browser.cjs
node tests/reliability.browser.cjs
node tests/mobile-ui.browser.cjs
.\tools-verify.ps1
```

브라우저 검사에는 Playwright와 Chromium이 필요하며 실제 Gemini 키를 호출하지 않고 합성 여행 데이터로 실행합니다. 실기기 카메라·키보드·메신저 링크 인식은 별도로 확인해야 합니다.

## 배포와 버전

정적 파일 배포는 저장소의 GitHub Pages 설정을 사용합니다. 새 버전에서는 `index.html`의 `APP_VER`·화면 배지·정적 자산 캐시 쿼리, `sw.js` 캐시 이름, `package.json`, `CHANGELOG.md`, `술술트래블신록.md`를 함께 갱신하고 사전 검증을 실행합니다. 최신 변경은 [CHANGELOG](CHANGELOG.md)에 기록합니다.
