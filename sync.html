기기 간 동기화 가이드

폰과 태블릿, PC 에서 같은 여행 일정을 보는 방법 · 100% 무료 (v1.7.2)

먼저 — 이 기능은 없어도 됩니다

술술트래블의 기본 사용 방식은 기기 로컬 저장 + JSON 파일 백업입니다. 한 대의 스마트폰에서만 쓴다면 별도 설정 없이 충분합니다. 설정(⚙) → 전체 백업 (JSON) 을 여행 전후에 한 번씩 받아 두는 것으로 완벽합니다.

1. 어떤 방식인가요?

제작자의 중앙 서버는 일절 없습니다. 대신 이용자가 직접 JSON 백업 파일을 다른 기기로 전달하거나, 이용자 본인의 GitHub 비공개(Private) 저장소를 연결하여 안전하게 동기화합니다.

기본 (JSON 백업)GitHub 동기화
비용없음 (완전 무료)없음 (GitHub 무료 계정)
기기 간 반영파일 전송 후 복원버튼 하나로 동기화
준비 작업없음 (즉시 사용)GitHub 계정 및 토큰 발급
데이터를 보는 사람나만 (내 기기)나만 (비공개 저장소)
기기 분실 시백업 파일로 복원새 기기에서 토큰으로 복원
GitHub 저장소는 반드시 비공개(Private)로 만드세요

공개(Public)로 만들면 여행 일정, 비행기 편명, 호텔 예약, 가계부 지출 내역이 인터넷에 전체 공개됩니다. 저장소를 만들 때 반드시 Private 옵션을 체크하세요.

2. 방법 1: 가장 추천하는 간편 JSON 백업 & 복원

  1. 내보내기: 상단 설정(⚙) → [전체 백업 (JSON)]을 누르면 sulsul_travel_backup_....json 파일이 다운로드됩니다.
  2. 전달하기: 다운로드된 파일을 카카오톡(나에게 보내기), 이메일, 클라우드 등으로 새 기기에 보냅니다.
  3. 가져오기: 새 기기에서 술술트래블을 열고 설정(⚙) → [백업 파일 복원]을 눌러 해당 파일을 선택하면 모든 여행이 완벽히 복원됩니다.

3. 스마트폰 변경 시 필수 체크리스트

기기 변경이나 브라우저 초기화 전에는 반드시 JSON 전체 백업을 받아 안전한 클라우드나 메일에 저장해 두세요.
