# 동작 시안 검증 기록

검증일: 2026-09-08~09. 대상: `design/travel-companion.html`. 실제 브라우저에서 가상 자료로 수행했다. 운영 앱이나 실제 AI·공동편집 서버의 테스트 결과가 아니다.

## 확인한 흐름

| 항목 | 실제 관찰 |
| --- | --- |
| 큰 계획 / 오늘 / 기록 / 준비 / 평생 여행장 | 각 화면 전환과 콘텐츠 표시 확인 |
| 비 상황 RePlan | 기존 일정과 실내·휴식 대안을 비교한 후 적용. 09:00 완료 항목과 18:00 고정 항목 유지 |
| 되돌리기 | 변경 전 13:30 산책·15:00 산책 복원, 버전 증가 |
| 동행자의 지연 제안 | 참여자 제안 시 원본 유지. 조정자 승인 후 14:30·16:00으로 변경 |
| 오래된 변경안 | 제안 후 방문 확인으로 버전 변경. 이전 제안 적용 시 거부 안내, 완료 기록 유지 |
| 수동 수정 | 폼 필드 이름이 폼 ID를 가리는 오류를 수정. 15:00 중복 입력은 거부하고 14:00 변경은 반영됨 |
| 열람자 | RePlan·방문 확인 버튼 비활성화. 실제 서비스 권한 검증은 서버 구현 대상 |
| 하루 확정 | 에세이 생성 전에 확인 대화상자 표시. 미확인 3개가 방문으로 변환되지 않음 |
| 비공개 메모 | 비공개·공유 메모를 각각 작성. 공동 에세이에는 공유 메모와 확인한 경험만 포함 |
| 에세이 편집·보관 | 편집본 저장 후 다른 여행을 열고 돌아와도 세션 안에서 유지 |
| 에세이 재생성 | 이전 초안과 사용자 편집본 2개 및 각 근거를 보존 목록에서 확인 |
| 키보드 | Escape로 대화상자 닫힘 확인. 전체 스크린리더 검증은 수행하지 않음 |

## 화면 크기

읽기 전용 DOM 검사로 `window.innerWidth`와 `document.documentElement.scrollWidth`를 측정했다. 스크롤바 때문에 문서 폭은 viewport보다 15px 작게 측정되었다.

| 화면 | viewport 폭 | 문서 scrollWidth | 결과 |
| --- | ---: | ---: | --- |
| 큰 계획 / 오늘 / 기록 / 준비 / 평생 여행장 각각 | 360 | 345 | 가로 넘침 없음 |
| 기록 | 390 | 375 | 가로 넘침 없음 |
| 큰 계획 | 1280 | 1265 | 가로 넘침 없음 |

360px 큰 계획 화면에서 본문이 좁아지는 문제를 발견해, 삽화를 본문 아래로 배치한 뒤 실제 화면을 재확인했다. 모바일 오늘 화면과 데스크톱 큰 계획 화면도 시각적으로 확인했다. 실제 iOS/Android 기기·사진 업로드·위치 권한은 검증 대상에 포함하지 않았다.

## 정적 확인과 범위

- Node `vm.Script`로 인라인 스크립트 문법 검사 통과.
- 새 산출물의 행 끝 공백 검사 통과. 기존 `index.html`의 미커밋 수정에 있던 7826행 공백은 이번 변경 범위에 포함하지 않음.
- 최종 시안의 8093 포트 페이지에서 수집된 콘솔 오류 없음.
- 8092 포트에서는 기존 운영 앱 서비스 워커가 다른 문서를 반환하는 현상이 있어, 최종 검증은 새 포트 8093의 독립 시안에서 수행. 캐시 갱신 문제는 개발 계획에 반영.
- 참고 시트는 읽기만 수행. 민감 식별자·예약번호·개인 정산 원문은 시안에 복사하지 않음.

## 명시적 한계

모든 역할은 같은 브라우저 세션의 시뮬레이션이다. 새로고침하면 체험 자료가 초기화되며 실제 장기 보관을 제공하지 않는다. 실제 지도·교통·날씨·티켓·LLM·사진·정산·오프라인 동기화는 연결하지 않았다. RePlan 후보는 정해진 예시 규칙이며 실제 이동 가능성을 증명하지 않는다. 각 거점의 상세 기능은 가운데 거점 예시에서 체험한다. 실제 제품의 트랜잭션·권한·복구·계획 제약 검증은 [개발 계약](delivery-plan.md)의 완료 기준을 따른다.
