# v1.3.0 구현 기록

작성일: 2026-09-10

## 운영 앱 반영 범위

- 여행 안의 기본 메뉴를 **큰 계획 / 오늘 / 기록 / 준비**로 정리했다. 기존 가계부와 동행·백업은 관련 화면의 보조 행동으로 유지했다.
- 날짜 목록을 목적지 거점별 큰 계획 카드로 묶었다. 남미·운남 기본 일정은 이동일의 도착지를 우선하고, 일반 여행은 `city`, `cityName`, `loc`, `route` 순으로 거점을 정한다.
- 오늘 화면에서 다음 일정, 완료 수, 방문 확인, 건너뜀, 지도, 순간 기록과 RePlan을 한 흐름으로 연결했다.
- 로컬 RePlan과 AI RePlan 모두 변경 전후 비교를 먼저 보여준다. 완료·고정 일정은 검증 단계와 적용 직전에 다시 보호하며, 여행 revision이 달라지면 적용하지 않는다.
- 서버가 없는 현재 공유 기능은 여행 사본 링크와 JSON 백업으로 정확히 설명한다. 실시간 공동편집 완료 문구와 영구 저장 보장 문구를 제거했다.
- 서비스 워커는 `st-shell-` 접두사의 술술트래블 캐시만 정리하고 RePlan 도메인 모듈을 오프라인 캐시에 포함한다.

## 검증

- `node --test tests/*.test.mjs`: RePlan 시간 이동, 자정 넘김, 완료·고정 보호, 정적 계약을 검증한다.
- `tools-verify.ps1`: 필수 파일·DOM 계약, JavaScript 파싱, 로컬 서버와 Edge 런타임 오류를 검사한다.
- 실제 브라우저에서 360px 화면의 큰 계획, 오늘, RePlan 검토와 거절 흐름을 확인한다.

## 다음 구현 경계

이번 릴리스는 현재 기기의 단일 사용자 저장 모델을 유지한다. 여러 동행자가 같은 원본을 실시간으로 수정하려면 인증, 역할 권한, 서버 revision, 오프라인 Outbox와 충돌 해결을 추가해야 한다. 사진을 포함한 장기 백업 이전, 확정 기록만 사용하는 에세이 생성, 근거가 표시되는 이동·예약 정보도 후속 단계다.
