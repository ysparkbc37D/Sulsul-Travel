# 기존 초안과 앱 업데이트의 구분 — v1.9.1

2026-10-08 사용자는 같은 앱 주소를 다시 열어도 이전에 등록된 초안이 그대로 나오는 문제를 제기했다. v1.9.0은 신규 방문 시 공개 예제를 변경했지만 이전 브라우저의 `st_trips_v2` 문서를 보존했다. 구 기본 초안도 `legacyExampleRetired`로 표식만 바꿨다. 이 기기용 확인·정리 동선을 제공하지 않은 것이 후속 문제였다.

일반 앱 주소는 최신 프로그램을 열지만 여행 데이터는 각 브라우저에 남는다. `#share=` 주소에는 공유 당시의 압축 JSON이 들어 있고, 앱을 배포해도 과거 링크의 내용은 바뀌지 않는다. 기본 앱으로 이동해도 이미 가져온 여행은 남는다. 짧은 서버 초대의 계획 갱신은 별도 협업 서비스에 연결된 경우에만 가능하다.

v1.9.1은 구 고정 ID 두 개와 구 예제/은퇴 표식이 함께 있는 여행만 구 기본 초안으로 안내한다. 허브·상세에서 설정의 데이터 탭으로 이동할 수 있고, 설정에서 일정을 확인하거나 해당 초안 하나를 삭제한다. 편집한 글·사진·지출도 삭제되는 것을 확인창에 알린다. 같은 이름의 개인 여행과 다른 ID의 사본은 삭제하지 않는다. 저장 성공 이후에만 State·보조 기록·사진을 정리한다. 저장 실패와 삭제 취소는 원문을 유지한다. 마지막 구 초안을 삭제한 뒤에도 가상 예제는 사용자가 선택해야 추가된다.

제목이나 도시를 추측해 기존 여행을 일괄 삭제하거나 새 예제로 자동 교체하지 않는다. 복원 자료에 같은 ID가 여러 개 있으면 개인 자료와 보조 사진을 잘못 지우지 않도록 삭제를 중단한다. 이전 링크/다운로드/다른 기기에 저장된 자료를 원격 회수하는 기능도 없다. 기본 앱 이동 버튼은 주소의 사본 데이터만 제거하며 여행 문서를 지우지 않는다.

검증은 실제 개인 자료 대신 합성 구 초안·개인 여행·사본을 사용한다. 삭제 승인/취소/저장 실패/새로고침, 마지막 초안 정리 후 예제 선택, 사본 주소에서 기본 앱 이동, 320–430px 화면을 확인한다. 공개 배포 목록의 개인정보 제외 검사는 계속 유지한다.
