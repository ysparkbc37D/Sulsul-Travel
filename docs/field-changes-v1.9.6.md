## 현장 사용

1. 카드에서 **시간·내용 수정**을 눌러 일차·시간·활동·메모·고정을 수정한다.
2. **취소·대체·지연**을 열면 취소, 새 대체 일정 작성, 지연 변경안 확인, 삭제를 선택할 수 있다.
3. 취소한 항목은 원본을 보관하며 **취소·건너뛴 일정**에서 복구한다. 대체 시 원래 항목의 기록과 사진은 그대로 두고 새 ID로 대체 일정을 추가한다.
4. 지연은 선택한 항목부터 같은 날 뒤쪽의 유연한 일정에만 적용한다. 완료·고정·기록·취소 항목은 보존한다. 변경 시각과 고정 시각을 넘는 경고를 확인한 뒤 확정한다. AI나 인터넷 없이 사용할 수 있다.
5. 삭제는 별도 확인하며 글·사진 기록은 남긴다. 취소와 달리 일정표에서 지운 항목 자체는 되돌리는 기능이 없으므로 복구가 필요하면 취소를 사용한다.

완료 항목의 취소·대체는 먼저 완료를 취소해야 한다. 사용자의 직접 편집은 가능하며 이미 작성한 기록의 날짜·제목 문맥은 유지한다. 변경안을 열어둔 뒤 계획이 바뀌면 적용을 거절한다. 저장 실패에서는 원본·입력·확인창을 유지한다.

## 검증과 한계

`tests/schedule-change.test.mjs`는 보호 일정·시간 범위·자정·취소 RePlan을 확인한다. `tests/schedule-change.browser.cjs`는 4개 모바일 폭의 한 줄 실제 배치, 고정 편집, 취소/복구, 원문·승인문·사진을 가진 대체, 지연 검토와 저장 실패, revision 충돌, 실제 삭제 확인, 두 준비물 보기 모드의 전문/체크 분리를 합성 자료로 검사한다. 기존 헤더·여행·구 워커 업그레이드·저장 경계도 확인한다.

최종 v1.9.6에서 단위·정적 검사 165건, 현장 변경 브라우저 12건, 헤더·허브 35건, 여행 화면 16건, 저장 경계 7건, 워커 업데이트 49개 검증, AI 신뢰성 28개 검증과 여행기 출력 검사를 통과했다. 배포 게이트와 69개 공개 파일 빌드도 통과했다. 사용자 기기의 저장소를 검사한 결과로 해석하지 않는다.

지연은 사용자가 지정한 분 단위 조정이다. 실제 교통 시간·예약 취소·대체 장소의 영업 여부를 조회하거나 예약을 취소하지 않는다. 고정 시각 경고는 모든 이동·예약 충돌 검사를 대신하지 않는다. 완료·취소·대체 상태와 기록은 여행기 모델 및 백업에 남지만 실제 서버 동행 공동편집 검증은 기존 미완료 범위다. Edge Chromium 모바일 검사는 실제 iOS 기기 검증을 대신하지 않는다.
