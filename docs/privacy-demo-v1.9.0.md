# v1.9.0 개인 여행과 공개 예제의 경계

2026-10-08. 이전 기본 KB와 목적지 팩에는 개인 계획에서 가져온 구체적 날짜·확정 항공편·예산·거래·일기가 포함되어 있었다. 첫 실행은 이를 공용 예제로 자동 저장했다. 설정 삭제/복원은 제목도 매칭해 개인 여행을 건드릴 수 있었고, 일반 삭제나 마지막 여행 삭제는 예제를 다시 넣었다. UI 기능 검증만으로 이 공개 경계를 확인하지 못했던 점을 수정한다.

## 새 시작 흐름

1. 신규 방문은 빈 여행 목록으로 시작한다. 어떤 여행도 자동 생성하지 않는다.
2. 큰 계획→하루 일정→글·사진→여행 이야기 흐름을 살펴볼 가상 타이베이·타이중 5일 예제를 제안한다. 선택하면 이 기기에 추가하고 중복으로 만들지 않는다.
3. 가상 날짜·시간·금액·기록임을 제안·카드·상세 화면과 각 기록에 표시한다. 실제 예약/교통 정보나 개인 경험으로 안내하지 않는다.
4. 설정의 `예제 초안 삭제` 또는 일반 카드 삭제로 제거한다. 거절·삭제 상태는 `st_demo_choice_v1`에 저장하고 다시 자동 제안/등록하지 않는다. 설정의 추가는 사용자가 다시 선택하는 동작이다.
5. 예제의 정확한 ID와 `isSample`·`demoTemplateId`를 함께 확인한다. 제목이 같은 개인 여행과 예제에서 만든 개인 사본은 예제 삭제 대상이 아니다.

문서 저장이 실패하면 여행·선택 상태를 되돌리고 실패를 표시한다. 저장 성공 뒤에만 일기 overflow와 미참조 사진 정리를 시도한다. 기존 기기의 구 공용 예제는 개인 로컬 여행으로 보존하고 더 이상 공식 예제 표식을 표시하지 않는다. 임의로 새 가상 예제로 덮어쓰거나 삭제하지 않는다. 구 `st_current_trip` 이관은 새 저장 문서가 없을 때 한 번만 수행하며, 빈 문서는 사용자가 삭제한 상태로 존중한다. 손상 문서도 정상 빈 문서로 덮어쓰지 않는다.

공유 링크로 진입할 때에는 예제를 끼워 넣지 않는다. 데이터가 들어 있는 사본 링크의 사용자 승인/거절 동작은 그대로 유지한다. 서버 초대와 기본 앱 주소를 열기만 해서 로컬 개인 기록을 업로드하는 동작은 추가하지 않는다.

## 공개 파일과 배포

`kb-travel.js`는 가상 예제만 담는다. 남미 팩은 일반 관광지·좌표·도시 안내를 유지하고 개인 일정의 확정 항공편·고정 기간·예약 금액·room code·동선 배열을 제거한다. 경로는 해당 사용자의 여행 데이터에서 구한다. 개인 계획 전체 적용 버튼과 실제 확정 내용을 담은 앱 변경 이력도 제거/일반화했다.

`tools/build-public.cjs`는 공개 파일과 서비스워커에 명시된 자산만 새로운 `public`에 복사한다. `vercel.json`의 `outputDirectory`를 이 디렉터리로 한정하므로 개발 문서·검사·첨부·SQL·참고 이미지·Git 파일은 산출물에 없다. 폴더 내부에 새 자료가 생겨도 목록 없이 배포하지 않는다. 심볼릭 링크는 거절하며 기존 비어 있지 않은 출력이나 허용 범위 밖 경로에는 쓰지 않는다. 새 캐시 버전과 KB/팩 URL 쿼리는 이전 공용 시드 자산을 다시 요청하게 한다. [Vercel 출력 디렉터리 공식 안내](https://vercel.com/docs/builds/configure-a-build#output-directory)

과거에 전달된 데이터 포함 링크, 이미 내려받은 JSON/브라우저 저장 데이터, 이전 배포 URL과 Git 기록은 이 변경으로 소급 회수되지 않는다. 실제 기존 기기의 여행은 보존하며 새 운영 주소의 신규 방문과 배포 파일에서 노출 경로를 차단한다.

## 검증

- 단위/계약 107개: 공개 KB의 개인 마커 부재, 가상 데이터 공유 왕복, 공개 출력의 제외 목록과 모든 서비스워커 자산 존재를 포함한다.
- `tests/demo-onboarding.browser.cjs` 9개 독립 HTTP 사례: 최초 방문/거절, 선택 추가/중복 방지, 설정 삭제/같은 제목 개인·사본 보존, 마지막 카드 삭제, 추가·삭제 저장 실패, 공유 승인/거절, 구버전 1회 이관, 구 예제 원문 보존을 검사한다. 320/360/390/430px 화면도 검사한다.
- 기존 모바일·저장/복원·오프라인·순간/일정 기록 회귀를 다시 실행한다. 실제 개인 여행·외부 API 키는 사용하지 않는다.

운영 배포 후 버전과 KB/팩의 가상 자료, 개발 문서·첨부·참고 이미지 경로의 404를 확인한다. 과거 배포와 Git 기록의 별도 삭제는 이번 릴리스에 포함되지 않는다.
