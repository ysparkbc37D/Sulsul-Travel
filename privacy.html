한 줄 요약

술술트래블은 중앙 서버가 없습니다. 회원가입도, 로그인도 없습니다. 기록한 모든 여정과 가계부, 사진은 이용자의 기기 안에만 저장되며 제작자에게 전송되지 않습니다. 제작자는 이용자의 어떤 개인정보도 수집·보관·열람하지 않습니다.

1. 수집하는 개인정보

없습니다. 이 앱은 이름·연락처·이메일·계정 등 어떤 개인정보도 요구하지 않고, 회원가입 절차 자체가 없습니다. 분석 도구(Google Analytics, Facebook Pixel 등), 광고 식별자, 추적 쿠키를 일절 사용하지 않습니다.

2. 이용자가 기록한 내용은 어디에 저장되나요

이용자가 등록한 여행 일정(여행명·기간·방문 도시·타임라인 스팟·메모·사진·가계부 지출 내역 등)은 브라우저의 저장 영역(localStorage 및 IndexedDB)에 저장됩니다. 이 영역은 이용자의 기기 안에만 존재합니다.

저장 키내용
sulsul_travel_trips등록한 모든 여행 일정 및 가계부 데이터(IndexedDB 연동)
sulsul_travel_theme선택한 테마 (모던, 라이트그레이, 딥블랙)
sulsul_gemini_api_keyAI 기능을 켠 경우의 본인 Google API 키 (§3 참고). 넣지 않으면 저장되지 않습니다

스마트폰을 바꾸거나 브라우저 데이터를 지우면 이 내용은 사라집니다. 그래서 앱은 JSON 전체 백업을 권장하며, 백업 파일은 이용자가 직접 안전하게 보관합니다.

3. 외부로 나가는 통신 (투명한 전부 고지)

저장은 기기 안에서만 이루어지지만, 앱이 동작하는 과정에서 아래 외부 서비스와 통신합니다.

대상시점전달되는 것
OpenStreetMap
tile.openstreetmap.org		 지도를 열어 동선을 볼 때 지도 타일 이미지를 가져오기 위한 접속 IP (제작자에게 개인정보가 전달되지 않음)
Google Gemini API
generativelanguage.googleapis.com		 설정에서 API 키를 넣은 뒤 AI 일정을 요청했을 때만 요청한 여행 목적지 및 일정 생성 프롬프트. 이용자 브라우저에서 Google 서버로 직접 통신하며 제작자의 서버를 거치지 않습니다.

4. 데이터의 파기 및 주권

이용자는 설정(⚙)의 [데이터 전체 초기화]를 통해 언제든지 기기 내의 모든 데이터를 즉시 영구 삭제할 수 있습니다.

5. 문의처

본 방침이나 앱에 관한 질문·제안은 아래 후원 및 개발자 블로그를 통해 문의하실 수 있습니다.
